Matlab code for Single-Molecule Data Analysis

These codes are based on Matlab2017a and used for manually click time segements for analyzing slopes and distances of helicase unwinding and translocation data measured via single-molecule magnetic trapping assays

DataAnalysisSlopeBttnfcn.m is the main code. mybttnfcn_.m is the function to be called

User guidlines are written in readme.docx
